Sixteen cards hide eight animals. Tap a card to turn it over, remember where everything is, and clear the board.

Start playing

How to play

  1. Tap any card to flip it and see the animal.
  2. Tap a second card. If the animals match, leave both face up.
  3. If they differ, tap each one again to turn it face down.
  4. Keep going until all eight pairs are face up.
  5. Press Turn all cards back to start a new round.

About this page

This page was built for a web design assignment on responsive layouts with HTML5 and CSS3. It uses no JavaScript at all. The cards flip with a hidden checkbox and the :checked selector, and the reset button is a plain HTML form reset.

  • Semantic HTML5: header, nav, main, section, form, footer
  • CSS Grid for the board and Flexbox for the navigation
  • CSS custom properties, 3D transforms and transitions
  • Media queries for phones, tablets and desktops
