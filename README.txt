Task 1: Responsive Web Page Design using HTML5 & CSS3
Project: "Pair Up" - a memory card game (HTML + CSS only, no JavaScript)

How to run
1. Unzip the folder.
2. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).

Files
- index.html     Page structure (semantic HTML5)
- css/style.css  All styling, layout and responsive rules

Concepts used
- Semantic tags: header, nav, main, section, form, footer
- CSS Grid (game board, hero layout) and Flexbox (header, navigation)
- CSS variables, 3D transforms, transitions, :checked and :focus-visible
- Media queries at 600px and 900px, mobile-first
- prefers-reduced-motion and print styles
